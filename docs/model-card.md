# Model card

## Summary

Predicts purchase likelihood for a completed or late-stage e-commerce browsing
session. The selected classifier is chosen by stratified cross-validation PR-AUC.
Its operating threshold is selected on a separate validation partition by
maximizing the configured expected-value scenario.

## Intended use

- Rank late-session visits for analyst-led, controlled conversion experiments.
- Compare aggregate behavioral cohorts and review model explanations.
- Support human decisions; do not automate high-impact decisions.

## Out of scope

- Early-session scoring before `PageValues` is available.
- Identifying or profiling individuals.
- Pricing, credit, access, employment, or eligibility decisions.
- Claiming that discounts or other interventions cause conversion.

## Data and features

The included anonymized dataset contains 12,000 sessions and 17 input columns.
`OperatingSystems`, `Browser`, `Region`, and `TrafficType` are categorical IDs
and are one-hot encoded with the other categorical fields. Robust scaling and
one-hot encoding are fitted inside each cross-validation fold. Derived features
include total pages, total session duration, product-page share, product time
per page, and the exit/bounce-rate difference.

`PageValues` is intentionally retained for late-session scoring. It is a
particularly strong signal and may encode information close to conversion.
Results should not be represented as early-session performance.

## Evaluation

Metrics, split sizes, selected threshold, cross-validation results, and the
test confusion matrix are generated by `python -m src.train` and stored under
`models/`. PR-AUC and purchase recall are emphasized due to class imbalance.
Expected-value settings in `config.yaml` are illustrative until replaced with
the retailer's actual contribution and intervention costs.

The initial reproducible run selected tuned CatBoost (depth 5, learning rate
0.04). On the held-out 2,400-session test split it achieved PR-AUC 0.866,
ROC-AUC 0.973, recall 0.971, precision 0.521, and F1 0.678 at threshold 0.24.
The confusion matrix (actual rows: no purchase, purchase; predicted columns:
no purchase, purchase) was `[[1687, 336], [11, 366]]`. These figures describe
the current random stratified split; re-training or changing the business
assumptions can change the selected model and results.

## Limitations and monitoring

The source is observational and does not establish intervention lift. Technical
and traffic-source identifiers can act as proxies and may drift. Evaluate
calibration, subgroup behavior, temporal stability, and intervention impact
before production deployment. Do not link scores to personal identifiers.
